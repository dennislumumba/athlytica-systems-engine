| Block | Timing | Rule |
|---|---|---|
| Cold Open Hook | 0–7s | COPPA-safe excitement line + signature locomotion shot; no CTAs |
| Setup | 7–25s | Scene parameters: surface (ice rink / inline park), props, objective stated in one kid-sentence |
| Action Loop 1–3 | 25–75s / 75–125s / 125–175s | Each loop = one locomotion mechanic + one learning beat + on-screen text overlay |

| Hook Outro | 205–220s | Retention question to camera ("YOUR turn?") + Sunday long-form tease |
